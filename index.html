Born Into Opportunity: How Childhood Environment Shapes the American Dream

Does where you come from determine where you end up in life?

Our Main Research Question

To what extent does the socioeconomic environment someone grows up in influence their future income, financial stability, and opportunities in adulthood?

Using data from the Opportunity Atlas, we track millions of U.S. children from childhood into adulthood to test whether two children born into equally poor families (at the 25th income percentile, around $27,000/year) end up with very different financial futures depending on where they grew up.

Code 
library(tidyverse)
library(haven)
library(plotly)

# Load county-level Opportunity Atlas outcomes and neighborhood characteristics
outcomes <- read_dta("data/county_outcomes_simple.dta")
covs <- read_dta("data/cty_covariates.dta")

county_data <- outcomes |>
  inner_join(covs, by = c("state", "county", "cz", "czname")) |>
  filter(!is.na(kfr_pooled_pooled_p25), !is.na(hhinc_mean2000), pooled_pooled_count >= 500) |>
  mutate(
    # Convert percentile rank (0 to 1) into 0 to 100 scale
    adult_income_pctile = kfr_pooled_pooled_p25 * 100,
    poverty_rate_2000 = poor_share2000 * 100
  )

1. Neighborhood Environment: Does Growing Up in a Wealthier Area Boost Adult Earnings?

Every dot below represents a U.S. county. Even though all of these children started in low-income families (the 25th percentile), their average adult income percentile varies dramatically depending on their childhood county’s average household income. Hover over any point to explore a specific area!

Code 
p_neighborhood <- county_data |>
  ggplot(aes(
    x = hhinc_mean2000,
    y = adult_income_pctile,
    size = pooled_pooled_count,
    color = poverty_rate_2000,
    text = paste0(
      "Area: ", czname, " (County FIPS: ", sprintf("%02d%03d", state, county), ")<br>",
      "Childhood Area Mean Income (2000): $", scales::comma(round(hhinc_mean2000)), "<br>",
      "Childhood Poverty Rate: ", round(poverty_rate_2000, 1), "%<br>",
      "Child's Avg Adult Income Rank: ", round(adult_income_pctile, 1), "th percentile"
    )
  )) +
  geom_point(alpha = 0.65) +
  geom_smooth(aes(weight = pooled_pooled_count), method = "lm", se = FALSE, color = "black", linewidth = 0.8) +
  scale_x_continuous(labels = scales::label_dollar()) +
  scale_color_viridis_c(option = "plasma", direction = -1, name = "Poverty %") +
  labs(
    title = "Childhood Community Income vs. Adult Earnings Rank",
    x = "Mean Household Income in Childhood County (2000)",
    y = "Child's Adult Income Percentile (Born at 25th Percentile)"
  ) +
  theme_minimal()

ggplotly(p_neighborhood, tooltip = "text")
